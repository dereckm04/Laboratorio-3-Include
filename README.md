# Laboratorio 3 - Include

Este repositorio contiene el trabajo realizado en el tercer laboratorio de PHP, enfocado en el uso de `include` y en la organización de diferentes archivos dentro de un mismo proyecto.

En este laboratorio se practica cómo separar partes del código en diferentes archivos y luego utilizarlas desde otro archivo PHP.

## ¿Qué hay en el repositorio?

El proyecto contiene:

* `index.php` — Página principal del ejercicio.
* `procesar.php` — Archivo encargado de procesar los datos.
* `includes/` — Carpeta donde se encuentran los archivos que se incluyen en el proyecto.
* `uploaded_files/` — Carpeta utilizada para almacenar archivos subidos.

## ¿Qué se utilizó?

* PHP
* HTML
* WAMP
* Visual Studio Code

## ¿Cómo ejecutarlo?

Para ejecutar el proyecto se puede utilizar **WAMP** como servidor local.

Primero se coloca la carpeta del proyecto dentro de:

```text
C:\wamp64\www\
```

Luego se inicia WAMP y se abre el proyecto desde el navegador:

```text
http://localhost/Laboratorio-3-Include/
```

Desde ahí se puede acceder al ejercicio y probar su funcionamiento.

## Objetivo

El objetivo de este laboratorio es practicar el uso de `include` en PHP y entender cómo dividir un proyecto en diferentes archivos para tener el código más organizado y poder reutilizar partes del mismo.
